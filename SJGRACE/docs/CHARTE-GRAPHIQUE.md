# Charte graphique — SJ GRACE MULTISERVICE (v2, identité officielle)

Couleurs prélevées sur le logo officiel : bleu SJ GRACE et jaune du monogramme « SJ ».

## Logo
- Monogramme « SJ » (jaune #F5B400 + blanc) sur fond bleu #006299, mention « SJ GRACE MULTISERVICE ».
- Fichiers : `assets/icons/logo-sj.png|webp` (en-tête, pied de page), `assets/images/logo-sj-grace.jpg|webp` (logo complet, page À propos), `assets/icons/icon-512.png`, `favicon-32.png`, `apple-touch-icon.png`.
- Nom à écrire **SJ GRACE MULTISERVICE** (avec espace).

## Couleurs
| Rôle | Variable CSS | Hex | Usage |
|---|---|---|---|
| Bleu profond | `--navy` | `#043a5e` | En-tête, héros, boutons sombres, titres |
| Bleu intermédiaire | `--navy-2` | `#00517f` | Dégradés |
| Bleu officiel SJ GRACE | `--navy-3` | `#006299` | Fonds du logo, survols, accents |
| Jaune officiel | `--gold` | `#f5b400` | Boutons d'action, filets, badges |
| Jaune clair | `--gold-light` | `#ffc83d` | Accents sur fond sombre |
| Jaune texte | `--gold-ink` | `#7f5d00` | Texte jaune sur fond clair (contraste AA) |
| Fond clair | `--cream` | `#f2f6fa` | Sections alternées |
| Encre | `--ink` | `#172636` | Texte courant |

## Typographie
Titres : Manrope 700–800 · Texte : Inter 400–700 · Sur-titres en majuscules espacées précédés d'un filet jaune.
